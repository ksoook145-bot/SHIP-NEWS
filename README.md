# SHIP NEWS + 쇼츠 생성 기능

기존 SHIP NEWS 웹사이트에 **🎬 쇼츠 생성** 메뉴를 추가한 버전입니다.
검색한 조선해양 뉴스나 관심기사를 골라 버튼 하나로 **세로형(9:16) 쇼츠 영상(mp4)** 을 자동으로 만듭니다.

영상에는 다음이 들어갑니다.
- 파도가 흐르고 배가 항해하는 **움직이는 배경** (기사 분야에 따라 컨테이너선·LNG선·군함)
- 상단 **진행바**, 제목이 아래에서 올라오는 **등장 애니메이션**, 핵심 키워드 **노란색 강조**
- 내레이션에 맞춰 바뀌는 **큰 자막**, 장면 사이 **부드러운 전환**
- **한국어 음성**(gTTS)과 직접 합성한 **배경음악**

- 기능 추가: 박혜찬 (2001253)
- 원본 웹사이트의 기능(회원·로그인, 뉴스 검색·분류, 관심기사, 커뮤니티, 통계, 관리자)은 그대로 유지했습니다.

---

## 1. 파일 구성

| 파일 | 설명 |
|---|---|
| `app.py` | 웹사이트 본체. 원본에 쇼츠 메뉴와 RSS 검색을 추가함 |
| `shorts.py` | **새 파일.** 쇼츠 영상을 만드는 코드 |
| `requirements.txt` | 설치할 패키지 목록 (4개 추가) |
| `샘플_쇼츠.mp4` | 쇼츠 결과물 예시 (테스트용 가상 기사, 음성 없이 배경음악만) |

`shipnews.db` 는 넣지 않았습니다. 처음 실행하면 자동으로 새로 만들어지고, 기존 DB를 계속 쓰려면 원래 파일을 같은 폴더에 두면 됩니다.

## 2. 실행 방법 (PC)

```bash
pip install -r requirements.txt
streamlit run app.py
```

브라우저가 열리면 왼쪽 메뉴에서 사용합니다.

## 3. 쇼츠 만드는 순서

1. **📰 뉴스** 메뉴에서 키워드로 검색 (예: `LNG선`, `자율운항`)
2. **🎬 쇼츠 생성** 메뉴로 이동
3. 기사 가져오기: `현재 검색 결과` 또는 `관심기사`(로그인 필요) 선택
4. 쇼츠에 넣을 기사 최대 3건 선택, 첫 화면 제목 입력, 음성·배경음악 사용 여부 선택
5. **🎬 쇼츠 만들기** 클릭 → 화면에서 재생, **⬇️ mp4 다운로드**

영상 구성: 첫 화면("N건 뉴스 한눈에") → 기사별 화면(분야·제목·출처·날짜·자막) → 마지막 화면(출처 안내)  
기사 3건 기준 약 30초이며, 만드는 데 PC에서 30초~1분 정도 걸립니다.

## 4. 바뀐 점

코드에서 `[쇼츠 추가]` 로 검색하면 바뀐 곳을 모두 찾을 수 있습니다.

1. **뉴스 검색 보완**
   GNews API 키가 없거나 오류가 나면 **구글 뉴스 RSS(무료, 키 불필요)** 로 자동 검색합니다.
   키가 있으면 기존처럼 GNews를 먼저 사용합니다.
   `.streamlit/secrets.toml` 파일이 없어도 오류가 나지 않도록 했습니다.
2. **🎬 쇼츠 생성 메뉴 추가** (메뉴 순서: 관심기사 다음)
3. **홈 화면 소개 문구** 에 쇼츠 기능 한 줄 추가

## 5. 알아둘 점

- **음성:** gTTS(무료)로 한국어 음성을 넣으며 인터넷이 필요합니다. 음성을 못 만들면 자막과 배경음악만 있는 영상으로 자동 제작됩니다.
- **배경음악:** 외부 음원을 쓰지 않고 코드로 직접 합성해 저작권 문제가 없습니다.
- **한글 폰트:** Windows(맑은 고딕), macOS, Linux(나눔·Noto) 폰트를 자동으로 찾습니다. 못 찾으면 `shorts.py` 의 `FONT_CANDIDATES` 에 폰트 경로를 추가하세요.
- **ffmpeg:** `imageio-ffmpeg` 패키지가 자동으로 포함해 따로 설치할 필요가 없습니다.
- **대본 다듬기 (선택):** 환경변수 `ANTHROPIC_API_KEY` 가 있으면 LLM이 내레이션 문장을 다듬고, 없으면 기사 제목·요약을 그대로 사용합니다.
- **저작권:** 기사 사진은 쓰지 않고 직접 만든 배경과 글자로만 화면을 구성하며, 마지막 화면에 출처를 표시합니다.
- 만든 영상은 `shorts_output/` 폴더에 저장됩니다.

## 6. 쇼츠 기능만 따로 테스트

```bash
python shorts.py
```

샘플 기사 3건으로 `shorts_output/` 에 영상이 만들어지면 정상입니다.
